# Automaton — сборки

Конструктор автоматизаций, который работает **на вашей машине**: сценарий
собирается на канве, выполняет его встроенный движок, и наружу ничего не
уходит. Здесь лежат готовые сборки — брать и пробовать.

> **Это тестовая версия.** Выпуск младше единицы: в программе могут найтись
> ошибки, а сценарии, собранные сейчас, могут потребовать правки после
> обновления. Поэтому просьба: пробуйте, ломайте и рассказывайте, что пошло не
> так, — [в задачах](../../issues).

**Исходный код закрыт** и здесь не выкладывается. Это намеренно, а не упущение:
раздаются сборки. Условия — в [LICENSE](LICENSE); коротко: скачали отсюда —
можете ставить и пользоваться на своих машинах, бесплатно и без ограничения по
времени; выкладывать у себя, продавать и оказывать с её помощью услуги другим
нельзя.

## Как поставить

**Linux.** `sudo apt install ./Automaton_0.5.4_amd64.deb` — зависимости
подтянутся сами. AppImage: `chmod +x` и запустить.

**Windows.** Двойной щелчок по `.msi`. Windows покажет синее окно SmartScreen
«Защита компьютера» — **это ожидаемо**: у сборки нет платного сертификата
подписи. «Подробнее» → «Выполнить в любом случае».

**macOS.** Открыть `.dmg`, перетащить программу в «Программы». При первом
запуске система скажет, что разработчик не проверен, — **тоже ожидаемо**:
учётной записи Apple Developer у программы нет. Правый щелчок по значку →
«Открыть» → «Открыть». Дальше запускается обычно.

**Сервер.** `sudo apt install ./automaton-server_0.5.4_amd64.deb`, потом
`automaton-server --help`: он слушает петлю, пароль спрашивает в терминале.

## Если что-то пошло не так

Напишите [в задачах](../../issues). Чтобы разбор не превратился в переписку,
приложите сразу:

* версию программы и вашу систему;
* что делали и что ожидали увидеть;
* журнал — он лежит рядом с данными программы:
  * Linux и macOS — `~/.local/share/com.automaton.app/automaton.log`
  * Windows — `%APPDATA%\com.automaton.app\automaton.log`

В журнал не попадают ни ваши пароли, ни содержимое сообщений — но прежде чем
прикладывать, гляньте на него сами.

## Обновления

Программа раз в сутки смотрит, не вышла ли новая версия, и говорит об этом в
окне. **Ставить она не станет**: запускать новый код на вашей машине в момент,
который выбрали не вы, — не её право. Наружу при этом не уходит ничего: ни
версия спрашивающего, ни какой-либо опознавательный знак.

Смотрит она в [`latest.json`](latest.json) — один файл в корне этого
репозитория:

```json
{
  "version": "0.5.4",
  "notes": "Что изменилось, в одну-две фразы — это читает человек в окне.",
  "where": ".../Automaton_0.5.4_amd64.deb",
  "builds": { "linux": "…", "windows": "…", "macos": "…" }
}
```

`where` — адрес для копий 0.2–0.4, которые про `builds` ещё не знали; `builds`
отвечает на вопрос «где взять программу для моей системы». Копии старше
читают только `where`, поэтому подменить его чем-то другим нельзя.

## Почему этот репозиторий отдельный и публичный

Чтобы лента обновлений работала у всех, не открывая исходный код: здесь только
сборки и файл о версиях. Сам код лежит в закрытом репозитории и сюда не
попадает.
