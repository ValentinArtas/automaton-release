# automaton-release

Здесь лежит одна вещь, которая нужна установленным копиям Automaton:
[`latest.json`](latest.json) — файл, по которому копия раз в сутки узнаёт, что
вышла новая версия.

```json
{
  "version": "0.2.0",
  "notes": "Что изменилось, в одну-две фразы — это читает человек в окне.",
  "where": "https://github.com/ValentinArtas/automaton-release/releases/download/v0.2.0/Automaton_0.2.0_amd64.deb",
  "sha256": "…"
}
```

Программа **смотрит и говорит, но не ставит.** Ставить самой значило бы держать
право запускать код на чужом компьютере в момент, который выбрал не владелец.
Поэтому всё кончается фразой на экране: «вышла новая, вот что изменилось, вот
где она лежит».

Наружу при этом не уходит ничего — ни версия спрашивающего, ни какой-либо
опознавательный знак: запрос, который нёс бы «кто спрашивает», превратил бы это
в способ считать людей, поставивших программу.

## Почему репозиторий отдельный и публичный

Исходники Automaton закрыты. Публичен здесь только этот файл — потому что его
должна читать любая копия на любой машине, без ключей и без учётной записи.

Право писать сюда стоит столько же, сколько исходники: в `where` приезжает
ссылка, которую программа предлагает владельцу нажать. Поэтому адрес читается
только по `https` — по простому `http` эта ссылка принадлежала бы не тому, кто
её выложил, а любому, кто оказался по дороге.

## Где что лежит

* `latest.json` — в корне ветки `main`, раздаётся GitHub Pages по адресу
  <https://valentinartas.github.io/automaton-release/latest.json>. Этот адрес
  вписан в каждую выданную копию навсегда, поэтому он и страница, а не файл на
  ветке: ветку однажды переименуют, и все копии в мире замолчат без единого слова.
* Пакеты — **вложениями к выпускам**, не в самом репозитории: каждый `.deb` — это
  десять мегабайт, которые остались бы в истории навсегда.

## Как выпускается новая версия

`scripts/release.sh <версия> "что изменилось"` в основном репозитории: проверка,
номер версии во все три места, где он есть, сборка пакета, `latest.json` с
отпечатком sha256. Выкладка — руками и нарочно.
